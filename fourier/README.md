# Projet Fourier (Octobre 2024)  
  
Projet de dessin de figures avec une décomposition périodique de la figure en séries de Fourier.  
Les figures peuvent être obtenues de deux manières :   
- à partir d'une image d'un fichier png avec des contours clairs (mode "contours") en précisant le nom du fichier dans le code
- à partir d'un dessin (mode "recording")  

# Démonstration  

La décomposition en séries de Fourier permet ici de représenter les figures avec des vecteurs en rotation uniforme mis bout à bout.
