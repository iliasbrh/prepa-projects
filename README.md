# List of my personal projects during the preparatory classes, after highschool  
  
These projects are simple Python curiosities that I did in my free time. They are all written in french since I did not care about writing in english back then.  
They include :  
- fourier : drawing figures from contours of images, using their Fourier decomposition
- mandelbrot : drawing chunks of the Mandelbrot's set and zooming to infinity (but it is extremely slow)  
- tipe : final project of preparatory classes where I made handwriter recognition (so author classification) among 5 of my classmates  
- reconnaissance_ecriture : my first handmade neural network (using only numpy) to recognize MNIST digits and letters
